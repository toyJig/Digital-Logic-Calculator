# Digital-Logic-Calculator
Calculator made from pure gate logic: I've always wondered how people make calculators and such in games like Minecraft and Build a Boat for Treasure so I ended up wanting to do something like this for the custom project week. The project ended up being easier than I thought but it was still pretty cool. Maybe I'll hop on Roblox and make this real quick...
